About Movie Explorer Portal

The Movie Explorer Portal is An Educational Static Web Development Project Crafted Specifically For The B.Tech 1st Year Web Designing & Web Technologies Lab Curriculum.

The core goal of this assignment is to teach students how to take a structured HTML document containing real-world movie metadata and apply progressive styling layers using standard CSS.

Syllabus Progression Roadmap

  1. Unit 1 — HTML5 Markup : Structuring semantic web documents, metadata, lists, tables, and form inputs.
  2. Unit 2 — CSS Fundamentals: Applying external style sheets, selectors, color rules, and understanding the Box Model (margins, borders, padding).
  3. Unit 3 — CSS3 & Responsive Design : Creating fluid layouts using Flexbox, CSS Grid, hover transitions, and media query breakpoints.
  4. Unit 4 — Responsive Frameworks : Refactoring custom CSS layouts into framework container grids (Bootstrap 5 / Tailwind CSS).
